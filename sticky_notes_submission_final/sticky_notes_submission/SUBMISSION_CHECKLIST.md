# Submission checklist

- [x] Django project named `sticky_notes`
- [x] `notes` app installed in settings
- [x] Note model with title and content fields (plus timestamps)
- [x] Initial migration (`notes/migrations/0001_initial.py`) included
- [x] Create, read/list, detail, update and delete views
- [x] ModelForm for note input and editing
- [x] App URLs included in the main URL configuration
- [x] Base template and note templates
- [x] CSS styling and static files configuration
- [x] `collectstatic` configuration
- [x] Automated tests for core CRUD paths and invalid/missing data
- [x] Use-case, class and sequence diagrams submitted as images (PNG/SVG), PDFs and a Markdown page
- [x] Combined PDF containing all three diagrams
- [x] Step-by-step project `README.md` and `diagrams/README.md`
- [x] `research_answers.md` with both requested research paragraphs
- [x] No virtual environment or generated database included

Before submitting, run `python manage.py check` and `python manage.py test` locally.
