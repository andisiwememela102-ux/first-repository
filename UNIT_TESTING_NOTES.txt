Unit Testing - Task Manager

Implementation tested:
task_manager.py

Use cases tested:
1. Valid and invalid date input.
2. Saving and loading task data.
3. Calculating task statistics.
4. Marking a task as completed.

Testing approach:
The tests use Python's built-in unittest framework and follow Arrange-Act-Assert.
Each test prepares its own data so that the tests remain independent and repeatable.

Run the tests with:
python -m unittest discover -v
